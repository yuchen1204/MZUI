# MZ UI

Project Zomboid Build 42 UI mod: cool grey-blue, flat, high-contrast reskin of the **title
screen, pause menu, settings and multiplayer server browser**. Original controls, callbacks, sounds, tooltips and controller
navigation stay in place. Disable the mod and restart to restore vanilla presentation.

## Status

0.1.0 preview. Syntax and headless regressions pass; the latest settings,
controller and multiplayer changes still require in-game visual validation.
Report layout issues with the game version, resolution, font scale and screenshot.
MIT licensed; see LICENSE in the release archive or repository root.

## Install

Copy `MZUI` into `Zomboid/mods/` and enable **MZ UI** in Mods. Restart the game.
Do not run a second title-menu/settings replacement (e.g. SlateUI, PZ Modern UI - Main Menu)
at the same time — they own the same screens.

Disable MZ UI and restart to restore the original presentation.
